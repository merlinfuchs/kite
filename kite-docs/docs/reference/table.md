# Tables

Tables are database-style content for your app. Create a table, define typed
columns, and add rows with generated IDs. Rows can be edited directly in the
table editor.

Supported column types are text, number, boolean, date (RFC 3339), JSON, and
reference. Reference columns point at another table's generated row IDs.
Existing stored variables remain available for flows that use the legacy
variable blocks.
