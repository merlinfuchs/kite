# Remove forum post tag

<EmbedFlowNode type="action_forum_post_tag_remove" />

The `Remove forum post tag` block removes a tag from a forum post.

### Options

> `Forum post` The ID of the forum post to remove the tag from.
>
> `Tag` The ID of the tag to remove.
