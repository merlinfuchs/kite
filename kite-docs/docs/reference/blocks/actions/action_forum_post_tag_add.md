# Add forum post tag

<EmbedFlowNode type="action_forum_post_tag_add" />

The `Add forum post tag` block adds a tag to a forum post.

### Options

> `Forum post` The ID of the forum post to add the tag to.
>
> `Tag` The ID of the tag to add.
