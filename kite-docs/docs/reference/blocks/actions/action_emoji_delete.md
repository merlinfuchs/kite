# Delete emoji

<EmbedFlowNode type="action_emoji_delete" />

The `Delete emoji` block deletes a custom emoji from a server.

The target can be the emoji's ID, the emoji itself like `<:name:123>`, or the result of a `Create emoji` block. The app needs the **Manage Expressions** permission.
