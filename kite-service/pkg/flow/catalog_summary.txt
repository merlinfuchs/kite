- Ask AI: Ask artificial intelligence a question or let it respond to a prompt. Needs ai_chat_completion_data (The prompt and model settings)
- Search the Web: Search the web for the latest information using AI. Needs ai_chat_completion_data (The search query and model settings)
- Create channel: Create a channel. Needs channel_data (Settings of the channel, thread or forum post)
- Delete channel: Delete a channel or thread . Needs channel_target (ID of the channel)
- Edit channel: Edit a channel or thread. Needs channel_target (ID of the channel), channel_data (Settings of the channel, thread or forum post)
- Get channel: Get a channel by ID. Needs channel_target (ID of the channel)
- Calculate Value: Evaluate math or other logical expressions and use the result later. Needs expression (Expr language expression to evaluate, written without surrounding {{ }}, e.g. arg('a') + arg('b'))
- Create forum post: Create a forum post. Needs channel_target (ID of the forum channel), channel_data (Settings of the channel, thread or forum post)
- Get server: Get a server / guild by ID. Needs guild_target (ID of the server)
- Send API Request: Send an API request to an external server. Needs http_request_data (The request to send)
- Log Message: Log some text which is only visible in the application logs. Needs log_level (Severity of the log entry), log_message (Text to write to the app's logs)
- Ban member: Ban a member from the server. Needs user_target (ID of the user)
- Edit member nickname: Edit a member in the server. Needs user_target (ID of the user), member_data (The changes to make to the member)
- Get member: Get a member by ID. Needs user_target (ID of the user)
- Kick member: Kick a member from the server. Needs user_target (ID of the user)
- Add role to member: Add a role to a member. Needs user_target (ID of the user), role_target (ID of the role)
- Remove role from member: Remove a role from a member. Needs user_target (ID of the user), role_target (ID of the role)
- Timeout member: Timeout a member in the server. Needs user_target (ID of the user), member_timeout_duration_seconds (How many seconds the member is timed out for)
- Unban member: Unban a member from the server. Needs user_target (ID of the user)
- Create channel message: Bot sends a message to a channel. Needs channel_target (ID of the channel to send the message to)
- Delete channel message: Bot deletes an existing message in a channel. Needs channel_target (ID of the channel), message_target (ID of the message)
- Edit channel message: Bot edits an existing message in a channel. Needs channel_target (ID of the channel), message_target (ID of the message)
- Get channel message: Get a message from a channel. Needs message_target (ID of the message)
- Pin channel message: Bot pins a message in a channel. Needs channel_target (ID of the channel), message_target (ID of the message)
- Create message reaction: Bot adds a reaction to a message. Needs channel_target (ID of the channel), message_target (ID of the message), emoji_data (The emoji to react with)
- Delete message reaction: Bot deletes a reaction from a message. Needs channel_target (ID of the channel), message_target (ID of the message), emoji_data (The emoji to remove the reaction of)
- Unpin channel message: Bot unpins a message in a channel. Needs channel_target (ID of the channel), message_target (ID of the message)
- Send direct message: Bot sends a private message to a user if the user allows it. Needs user_target (ID of the user to send the message to)
- Generate Random Number: Generate a random number in a range. Needs random_min (Smallest number that can be generated), random_max (Upper bound of the generated number. The number is always below it)
- Create response message: Bot replies to the interaction with a message (only in command, component_button, component_select_menu flows)
- Defer response: Bot defers the response to the interaction to give time for further processing (only in command, component_button, component_select_menu flows)
- Delete response message: Bot deletes an existing interaction response message (only in command, component_button, component_select_menu flows). Needs message_target (ID of the response message, or '@original' for the first response to the interaction)
- Edit response message: Bot edits an existing interaction response message (only in command, component_button, component_select_menu flows). Needs message_target (ID of the response message, or '@original' for the first response to the interaction)
- Get Roblox User: Get a Roblox user by ID or username. Needs roblox_user_target (ID or username of the Roblox user, depending on roblox_lookup_mode), roblox_lookup_mode (Whether roblox_user_target is an ID or a username)
- Get role: Get a role by ID. Needs role_target (ID of the role)
- Set status: Change the status and activity of the bot. Needs status_data (The status to set)
- Create thread: Create a thread. Needs channel_data (Settings of the channel, thread or forum post)
- Add member to thread: Add a member to a thread. Needs channel_target (ID of the thread), user_target (ID of the user)
- Remove member from thread: Remove a member from a thread. Needs channel_target (ID of the thread), user_target (ID of the user)
- Get user: Get a user by ID. Needs user_target (ID of the user)
- Delete stored variable: Delete the value of a stored variable
- Get stored variable: Get the value of a stored variable
- Set stored variable: Set the value of a stored variable. Needs variable_value (Value to store), variable_operation (How the value is combined with the stored one. increment and decrement add or subtract a number)
- Join voice channel: Bot joins a voice channel. Needs channel_target (ID of the voice channel to join)
- Leave voice channel: Bot leaves its voice channel in a server
- Channel Condition: Run actions based on a channel.. Needs condition_base_value (ID of the channel that each branch checks)
- Comparison Condition: Run actions based on the difference between two values.. Needs condition_base_value (Value that each branch compares against)
- Match Channel: Run actions if the channel meets the criteria.. Needs condition_item_mode (Whether the base value has to match this branch's value)
- Match Condition: Run actions if the two values are equal.. Needs condition_item_mode (How the condition's base value is compared to this branch's value)
- Match Role: Run actions if the role meets the criteria.. Needs condition_item_mode (Whether the base value has to match this branch's value)
- Match User: Run actions if the user meets the criteria.. Needs condition_item_mode (What to check about the user)
- Role Condition: Run actions based on a role.. Needs condition_base_value (ID of the role that each branch checks)
- User Condition: Run actions based on a user.. Needs condition_base_value (ID of the user that each branch checks)
- Handle Errors: Handle errors that occur in the flow after this block.
- Run a loop: Run a set of actions multiple times.. Needs loop_count (How many times the loop runs)
- Exit loop: Exit out of the loop.
- Wait: Pause the flow for a set amount of time.. Needs sleep_duration_seconds (How many seconds to wait before continuing)
- Command Argument: Argument for a command. (only in command flows). Needs name (Name of the argument. Its value can be read with {{arg('name')}}), description (Description of the argument shown in Discord), command_argument_type (Type of value the user has to enter)
- Command Contexts: Define where your command should be available. By default, it will be available everywhere. (only in command flows)
- Command Permissions: Make the command only available to users with the specified permissions. (only in command flows). Needs command_permissions (Discord permission bitfield. Only members with all of these permissions can see and use the command)
- Event Filter: Filter events based on their properties. (only in event_discord flows). Needs event_filter_target (Property of the event to filter on), event_filter_mode (How the property is compared to the filter value), event_filter_value (Value to compare against. This is fixed text, placeholders aren't supported)
- Show Modal: Show a modal to the user and suspend the flow until the user submits the modal. (only in command, component_button, component_select_menu flows). Needs modal_data (The modal to show)
