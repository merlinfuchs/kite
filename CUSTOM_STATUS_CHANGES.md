# Multi-status + rotation changes

Built on top of a fresh clone of github.com/merlinfuchs/kite (not a fork).

## What changed

Backend (kite-service):
- internal/model/app.go — AppDiscordStatus is now a config object: `Statuses []AppDiscordStatusEntry`, `ActiveID`, `RotateEnabled`, plus an `ActiveEntry()` helper.
- internal/core/gateway/helpers.go — presence is built from the active entry.
- internal/core/gateway/gateway.go — a per-connection goroutine rotates through all statuses every 60s when `RotateEnabled` is true (see `applyStatusRotation`, `statusRotationInterval`). Started on connect, restarted on config change and on token-change reconnects.
- internal/api/wire/app.go, internal/api/handler/app/handler.go — request/response types and the `PUT /v1/apps/:id/status` handler now carry the list of statuses; new entries without an ID get one from the existing `util.UniqueID()`.
- No SQL migration: `discord_status` is already a JSONB column, so the shape change is transparent. Old single-status rows just deserialize to an empty status list (falls back to Kite's default presence) rather than erroring.

Frontend (kite-web):
- src/components/app/AppSettingsPresence.tsx — rewritten: add/remove statuses, a radio to pick which one is active, and a switch to rotate through all of them every minute (disabled/auto-reset below 2 statuses).
- src/lib/types/wire.gen.ts — hand-updated to match the new Go wire types (this file is normally generated by `tygo`, per kite-service/tygo.yaml; regenerate with `tygo generate` from kite-service if you have it installed, and it should produce the same shape).

## Verified

- `gofmt -e` (syntax) passes on every changed Go file.
- Full `go build` wasn't possible in the sandbox this was built in (repo requires Go 1.25, and some dependencies do too, but the network there couldn't fetch a toolchain that new) — recommend running `go build ./...` and `go vet ./...` yourself before deploying.
- Frontend: `tsc --noEmit`, `eslint`, and `next build`'s type-check/lint phase all pass with zero issues on the changed files.
